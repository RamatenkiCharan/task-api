\# Task API



A simple CRUD REST API built with Python and FastAPI for managing a to-do list.



\## Features



\- Create tasks

\- Get all tasks

\- Get a task by ID

\- Update a task

\- Delete a task

\- Health check endpoint

\- Input validation

\- Proper HTTP status codes

\- Interactive Swagger API documentation

\- In-memory data storage



\## Tech Stack



\- Python

\- FastAPI

\- Pydantic

\- Uvicorn

\- Swagger UI

\- Git \& GitHub
